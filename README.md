# astro-front

Frontend en React + React Router para un sitio personal de astrología, tarot y numerología.

## dependencias

- React 18
- React Router 6
- Vite 5
- Tabler Icons

## instalación y ejecución

```bash
npm install
npm run dev
```

Abrir `http://localhost:5173` en el navegador.

## rutas

- `/` inicio
- `/escritos` textos y reflexiones
- `/videos` charlas, en cámara
- `/sesiones` tipos de sesión
- `/contacto` formulario de contacto

## estructura

- `src/components/` componentes reutilizables (`Navbar`, `Button`, `Card`, `SectionTitle`)
- `src/pages/` una página por ruta
- `src/index.css` estilos globales con la paleta exacta y tipografías
